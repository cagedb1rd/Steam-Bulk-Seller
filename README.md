# Steam-Client-Injected-Bulk-Seller

> **Steam 客户端内嵌批量售卖工具**：直接在 Steam 官方桌面客户端（黑色客户端）库存界面注入原生级批量挂单面板

---

## 📌 项目背景与解决痛点

在 Steam 官方客户端内，当玩家需要售卖大量相同物品（如 CS2 箱子、贴纸胶囊、集换式卡牌、批量饰品）时，官方界面仅支持逐件手动点击“出售 -> 输入价格 -> 确认”，数十上百件物品的重复点击极其耗时耗力。

市面上现有的第三方批量上架方案通常存在以下痛点：
1. **外部 GUI 软件**：需要手动输入账号密码或扫码登录，存在凭证泄漏风险，且经常因本地 Cookie 文件被客户端加锁而读取失败；
2. **浏览器插件**：必须在外部浏览器（Chrome/Edge 等）中登录 Steam 网页版，受限于国内网络环境与跨域证书问题，经常打不开或频繁掉线；

**Steam-Client-Injected-Bulk-Seller** 采用**客户端内嵌架构**：通过 Steam 原生支持的 CEF 调试协议，将极简操作面板直接注入到桌面客户端的“库存”页面中，在完全保留官方原生体验与会话安全的前提下，提供高效的同类合并与批量上架功能。

---

## ⚙️ 核心原理

Steam 桌面客户端的前端渲染基于 **Chromium Embedded Framework (CEF)** 构建。

```
+-------------------------------------------------------------------------+
|                         Steam 官方桌面客户端                             |
|  +-------------------------------------------------------------------+  |
|  |                 CEF 内置浏览器 (127.0.0.1:8080)                    |  |
|  |  +-------------------------------------------------------------+  |  |
|  |  | 社区“库存”页面 (已天然具备官方登录态、SessionID 与 CSRF 保护)   |  |  |
|  |  |                                                             |  |  |
|  |  |   [⚡ 批量售卖] <-- 由 injector.py 通过 CDP 协议无感注入      |  |  |
|  |  +-------------------------------------------------------------+  |  |
|  +-------------------------------------------------------------------+  |
+-------------------------------------------------------------------------+
                                    ▲
                                    │ CDP WebSocket (Runtime.evaluate)
                                    │
                    [ injector.py / run.py 守护进程 ]
```

1. **零登录配置**：直接复用客户端当前正在运行的网页上下文，调用原生 `window.g_sessionID`，完全不触碰账号密码与本地 Cookie 文件；
2. **纯本地回环通信**：通过官方提供的 `-cef-enable-debugging` 启动参数开放本地调试端口（仅监听 `127.0.0.1:8080`），外部网络无法访问；
3. **CDP 协议轻量注入**：利用 Chrome DevTools Protocol (CDP) 监听库存页面生命周期，在页面就绪时执行轻量级纯原生前端脚本 `injected_script.js`。

## ✨ 核心特性

- 🖥️ **原生客户端内嵌体验**：UI 依照 Steam 官方暗蓝/黑灰视觉规范设计，原生嵌入顶部操作栏，支持 ESC 键关闭与自适应分辨率。
- 🔑 **免登录**：不写本地凭据，不劫持网络请求，不产生任何外置登录窗口。
- 📦 **智能同类物品聚合**：自动读取客户端当前选中的游戏库存数据，将散落的相同物品（按 `market_hash_name` 和 `classid`）聚合并显示总数。
- 📊 **双向行情**：
  - 🟢 **最高求购价 (秒出)**：直接匹配市场当前最高买单。
  - 🔴 **最低在售价 (排队)**：获取当前货架最低售卖底价。
  - 🛡️ **现代 React/SSR 架构适配**：全面兼容 Steam 现代 SSR 架构下的 `item_nameid` 提取（兼容 `SSR.loaderData`、属性与内联数据）。
  - 🚀 **官方 `priceoverview`**：针对无求购单的物品（如带磨损枪皮）或接口限频，自动降级至官方公开价格接口，确保在售价永不卡死。
  - 💾 **5 分钟缓存**：通过 `sessionStorage` 对价格结果进行 5 分钟安全缓存，杜绝重复点选触发 429。
- ⚡ **核心避坑算法（抢首位）**：
  - Steam 市场对买家支付金额存在 5% 基础费 + 10% 发行商费（最低各 1 分）的阶梯向上/向下取整特性。若直接按买家价减 1 分反算，极易由于舍入规则被 Steam 强制改回原价或过度折价。
  - 本工具采用**单调二分法精确搜索卖家最大合法实收分值**，确保买家在市场看到的货架总价严格比当前最低价便宜 1 分钱，精准抢占在售队列第一位。
- ⏱️ **拟人化动态延时与可调滑块**：
  - 默认采用 **1.0 秒基准 + 0~100ms 随机抖动** 拟人化提交逻辑，有效防范固定频率请求检测。
  - UI 界面内嵌 **【挂单延时间隔】滑动条**（范围 `0.5s ~ 2.0s`，步长 `0.1s`），支持用户实时微调挂单节奏。
  - 单线程串行提交，遇 429 限流自动进入 10 秒安全冷却重试机制。

## 🚀 两种使用方式

### 方式一：单文件绿色免安装版（推荐普通玩家）
无需安装任何 Python 运行环境或第三方库，开箱即用：
1. 前往 GitHub 仓库的 **[Releases]** 页面，下载最新的 `SteamBulkSeller.exe`；
2. 双击运行 `SteamBulkSeller.exe`：
   - 若首次运行检测到客户端未开启调试端口，程序将**全自动定位 Steam 并在桌面快捷方式追加 `-cef-enable-debugging` 参数**，并友好提示是否一键重启 Steam；
   - 调试端口就绪后，控制台将自动转入无感常驻监听状态；
3. 打开 Steam 桌面客户端，点击顶部导航 **【个人昵称】 -> 【库存】**，即可在界面上方看到原生的 **【⚡ 批量售卖】** 按钮！

---

### 方式二：Python 源码运行方式（适合开发者 ）
1. **环境准备**：Windows 10 / 11，已安装 Python 3.8 或更高版本。
2. **克隆仓库与安装极简依赖**：
   ```bash
   git clone https://github.com/your-username/Steam-Client-Injected-Bulk-Seller.git
   cd Steam-Client-Injected-Bulk-Seller
   pip install -r requirements.txt
   ```
3. **一键自动配置环境**：
   ```bash
   python setup_steam.py
   ```
4. **启动守护程序**：
   ```bash
   python run.py
   ```
5. 打开 Steam 客户端库存界面开始使用。

---

### 🛠️ 开发者：如何自行打包为 EXE
若您对源代码进行了修改并希望重新打包单文件 EXE，只需运行仓库自带的自动化构建脚本：
```bash
python build.py
```
打包成功后，单文件便携可执行程序将输出至 `dist/SteamBulkSeller.exe`。

## 🖥️ 客户端实际操作步骤

1. 打开 Steam 桌面客户端，进入任意支持市场的游戏库存（如 CS2、Dota 2、TF2 等）；
2. 页面顶部操作栏将出现 **【⚡ 批量售卖】** 按钮（右下角同时备有保底悬浮按钮）；
3. 点击呼出面板，在左侧选择需要售卖的物品（支持中英文关键词实时搜索）；
4. 右侧选择定价策略（⚡ 以求购价秒出 / ⚡ 抢首位避坑算法 / ⏳ 跟随最低在售）；
5. 根据需要微调 **【⏱️ 挂单延时间隔】** 滑动条（默认 1.0 秒 + 0.1s 随机抖动），设定售卖数量；
6. 点击 **【🚀 开始批量上架】**；
7. 全部挂牌提交后，若涉及需要人工确认的物品，打开官方 **Steam 手机 App -> 确认** 页面查看并批准即可；小额物品通常已直接上架成功。

## ❓ 常见问题排查 (FAQ)

#### Q1：运行 `run.py` 提示无法连接 8080 端口？
- 确认是否已通过包含 `-cef-enable-debugging` 的快捷方式启动 Steam；
- 确认任务管理器中没有残留的旧版 Steam 进程。可完全退出 Steam 后重新运行 `setup_steam.py` 并选择自动重启。

#### Q2：在客户端进入库存页面后没有看到【⚡ 批量售卖】按钮？
- 检查 `run.py` 控制台是否打印了 `[√] 成功向 Steam 客户端库存页面注入批量售卖插件！`；
- 如果未打印，请在客户端库存页面任意空白处右键选择“重新载入”；
- 页面右下角同时备有保底悬浮按钮，可直接点击。

#### Q3：会不会导致封号或 VAC 封禁？
- **不会**。`-cef-enable-debugging` 是 Chromium / CEF 官方提供的标准开发者参数；
- 本工具全程不注入任何游戏进程内存，不篡改 Steam.exe 二进制文件，仅仅是对网页 DOM 与市场公开 Web API 的正常调用；
- 最终交易确认完全由用户在官方手机 App 上手动完成，符合官方交易规范。
